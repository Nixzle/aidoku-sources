# Comix v131 update feed

This dedicated source list restores the maintained Aidoku Community Comix
implementation. It removes the custom hidden-WebView transport used by v128–v130
and delegates Cloudflare handling to the repaired native path in Aidoku 0.9.

Add this URL in Aidoku Settings > Source Lists:

`https://nixzle.github.io/aidoku-sources/comix-v131/index.min.json`

Aidoku 0.9 or newer is required. Back up Aidoku before testing and do not delete
the existing library. Website challenges and premium permissions remain enforced.
