# Comix v129 update feed

This dedicated source list gives Aidoku a fresh manifest URL for the Comix v129
reader candidate. It is separate from the normal catalog because Comix remains
quarantined until the affected iPhone passes real reader acceptance.

Add this URL in Aidoku Settings > Source Lists:

`https://nixzle.github.io/aidoku-sources/comix-v129/index.min.json`

Aidoku 0.9 or newer is required. Back up Aidoku before testing and do not delete
the existing library. Website challenges and premium permissions remain enforced.
